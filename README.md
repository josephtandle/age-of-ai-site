# How to Stand Out in the Age of AI

Standalone site for Tiyana Gori's workshop page.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Main files

- `src/app/page.tsx`: site entrypoint
- `src/content/tiana-ai-positioning-workshop.tsx`: main workshop content
- `src/components/CodeBlock.tsx`: editable copy-and-paste prompt blocks

## Deploy

This repo is intended to deploy to:

- `https://ageofai.mastermindshq.business`

Vercel can be connected directly to this repository so changes pushed to `main` publish the site.
